# TestGit

用于测试和学习 Git、GitHub 相关操作的仓库。

- 学习 `git init`、`git add`、`git commit`
- 学习远程仓库 `git remote add`、`git push`、`git pull`
- 练习分支、合并等操作
- 练习 PR：从功能分支合并到 dev

## 本地常用命令

```bash
git status          # 查看状态
git add .           # 添加所有更改
git commit -m "说明" # 提交
git push            # 推送到远程
git pull            # 从远程拉取
```
